# Bank Queue Management System

A simple web-based Bank Queue Management System demonstrating the FIFO (First-In, First-Out) queue data structure.

## Features
- Add customers to the rear of the queue (Enqueue)
- Serve the customer at the front (Dequeue)
- Display the current queue
- Show the next customer to be served
- Clear the queue
- Automatic ticket numbers
- Responsive interface

## Data Structure
The application uses a JavaScript array as a queue:
- `push()` adds a customer to the rear.
- `shift()` removes the customer from the front.

## Deployment
This is a static HTML/CSS/JavaScript project. It can be deployed using GitHub Pages, Netlify, or Vercel.
